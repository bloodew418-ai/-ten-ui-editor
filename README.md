# TEN UI EDITOR v0.1

スマホ上で部品の位置・サイズを直接いじり、結果を **PNG + JSON** で実装側へ渡すための簡易エディタ。

TEN X AUTOのスマホUIだけでなく、任意のキャンバスサイズ・任意の画面／画像に流用できる。依存ライブラリなし、`index.html` 1ファイルで完結し、iPhoneのホーム画面アプリとしても動く。

## 流用のしかた

同じ操作系（ドラッグ・四隅リサイズ・横のサイズバー・Undo・PNG/JSON）を、用途ごとに使い回すための仕組みが3つある。

### 1. プロジェクト

画面いちばん上のプルダウンで切り替える。プロジェクトごとに下書き・参考画像・配置した画像が別々に保存されるので、TEN X AUTOとSPACE FISHINGを行き来しても混ざらない。`＋新規` で作ると、そのとき選んでいるキャンバスサイズの空プロジェクトができる。

### 2. キャンバスサイズ

プリセットから選ぶか、数値を直接入れて `適用`。

| 用途 | サイズ |
|---|---|
| スマホ画面 | 390 × 844 |
| スマホ大 | 430 × 932 |
| 正方形（Instagram等） | 1080 × 1080 |
| X 横長 | 1200 × 675 |
| サムネ | 1280 × 720 |
| ストーリー | 1080 × 1920 |

サイズを変えても部品の座標はそのまま残る（自動リサイズはしない）。スライダーの上限はキャンバスに追従する。

### 3. 画像部品

`画像` ボタンで写真やスクショを部品として置ける。ドラッグ・リサイズ・角丸・重ね順はほかの部品と同じ。枠に対して `cover`（中央基準で切り抜き）で表示される。サムネや告知画像を作るならこれが主役になる。

画像の実体はJSONではなく端末内に持つ。他端末や実装担当へ渡すときは「画像をJSONに埋め込む」をONにしてから書き出す。

## ファイル構成

```
index.html      本体（これ1つで動く）
manifest.json   ホーム画面アプリの設定
sw.js           オフライン用
icon-180.png    ホーム画面アイコン（iPhone）
icon-192.png    アイコン（Android / ブラウザ）
icon-512.png    アイコン（起動画面）
```

## 起動方法

- **PC**: `index.html` をブラウザで開くだけ。
- **iPhone（お試し）**: iCloud Driveに置いてファイルAppからSafariで開く。
- **iPhone（本番）**: 下の手順でGitHub Pagesに置き、ホーム画面に追加する。

データはすべて端末内（localStorage）に保存される。サーバー側には何も送らない。

## iPhoneのホーム画面アプリにする

### 1. GitHub Pagesに置く

1. GitHubで公開リポジトリを作る（例 `ten-ui-editor`）
2. 上の6ファイルをリポジトリ直下に置く
3. Settings → Pages → Source を `main` / `root` にして保存
4. 1〜2分待つと `https://ユーザー名.github.io/ten-ui-editor/` で開ける

**HTTPSで配信することが必須。** file:// や http:// ではオフライン動作（Service Worker）が有効にならない。

### 2. ホーム画面に追加

iPhoneのSafariでそのURLを開き、下の共有ボタン → `ホーム画面に追加`。

追加すると:

- Safariのアドレスバーとタブバーが消えて全画面になる
- 独立したアプリとしてタスク切替に並ぶ
- 一度開いたあとは機内モードでも起動する
- ステータスバー分の余白は自動で確保される（Safe Area対応済み）

初回にSafariで開いたときだけ、画面上部に追加手順の案内が出る。`閉じる` を押すと二度と出ない。

### 3. 更新のしかた

ファイルを差し替えてGitHubにpushすれば、次にオンラインで起動したときに反映される。反映されない場合は `sw.js` の1行目付近にある `ten-ui-editor-v1` の数字を `v2` に上げてpushする。

### ホーム画面から起動したときの注意

standalone表示ではファイルの自動ダウンロードが効かないことがある。そのため:

- PNG → 書き出し後に出る `PNGを共有・写真に保存` ボタン、またはプレビュー画像の長押し
- JSON → `コピー` ボタン、または `JSONを共有する` ボタン

を使う。共有ボタンからは、写真アプリ・ファイルApp・LINE・メモなど普通の共有先へそのまま渡せる。

## スマホでの使い方

| 操作 | やり方 |
|---|---|
| 選択 | 部品をタップ |
| 移動 | 部品を1本指でドラッグ |
| リサイズ | 選択中の四隅の丸を1本指でドラッグ |
| 微調整 | キャンバス下のスライダー / 数値入力 |
| 選択解除 | 白い余白をタップ |

### 横のサイズバー

画面右端の縦タブ「サイズ」をタップすると、幅・高さ・文字サイズの縦スライダーが横から出てくる。キャンバスを見たまま調整できるので、下のパネルまでスクロールしなくていい。

- ＋ / − は1タップで4px（文字サイズは1px）。4pxスナップOFFなら1px刻み。
- 開閉状態は記憶される。閉じるとタブだけ残る。
- 未選択のときは薄くなって操作できない。

- 表示倍率は画面幅に合わせて自動で変わる（上部に倍率表示）。JSONの座標は常にキャンバスの論理サイズ基準。
- `4pxスナップ` をONにすると位置・サイズが4px刻みに揃う。
- レイヤー一覧をタップしても選択できる。リストの**下にあるものほど前面**。
- 編集するたびに自動で下書き保存される。次回開くと前回の続きから始まる。

## JSON仕様

JSONが実装値の正本。PNGは見た目確認用。

```json
{
  "version": "0.1",
  "canvas": { "width": 390, "height": 844 },
  "elements": [
    {
      "id": "settings",
      "type": "button",
      "text": "設定",
      "x": 16, "y": 56,
      "width": 72, "height": 34,
      "fontSize": 14,
      "borderRadius": 10,
      "fill": "#111827",
      "textColor": "#ffffff",
      "fontWeight": 700,
      "zIndex": 20
    }
  ]
}
```

- `type` : `button` / `text` / `card` / `image`
  - `button` … テキストを上下左右中央寄せ
  - `text` … 余白8pxで左上寄せ
  - `card` … 余白10pxで左上寄せ
  - `image` … `src` の画像を枠に対してcover表示
- `src` : image部品のみ。`asset:xxx`（端末内保存）または `data:image/...`（埋め込み書き出し時）
- `fill` : `#rrggbb` または `"transparent"`
- `fontWeight` : `400` または `700`
- `zIndex` : 小さいほど背面。前面/背面ボタンは隣の要素とzIndexを入れ替える。
- 改行は `\n` でそのまま反映される。

読み込み時に型・範囲をチェックし、不正値はデフォルトへ丸める。IDが重複していれば自動で `_2` を付けて一意化する。

「書き出す」→「コピー」でテキストを渡す、または「JSONファイルを保存」で `.json` を渡す。復元は「読み込む」またはファイル選択から。

## PNG出力

1. 倍率を選ぶ（1x / 2x / 3x、初期値3x = 1170×2532px）
2. 参考画像を焼き込むかどうかをチェックで選ぶ
3. `PNGを書き出す`

- 選択枠とリサイズハンドルは出力に含まれない（DOMではなくcanvasへ描き直しているため）。
- iPhoneでは自動ダウンロードが効かないことがある。その場合はボタン下に出るプレビュー画像を長押しして「写真に保存」。
- 3xでcanvas上限に当たった場合は自動的に2x→1xへ落として再試行する。

## 参考画像

- 画像を選ぶとキャンバス背景にガイドとして表示される。opacityと表示/非表示を調整可能。
- 参考画像は**JSONには含めない**。端末のlocalStorageに別キー（`ten_ui_editor_v01_guide`）で保存する。別端末へ渡すときは画像を別途送ること。

## 既知の制限

- フォントは端末のシステムフォント依存。PNGとブラウザ表示で文字幅が微妙に違う場合がある。
- テキストの折り返しは1文字単位。英単語の途中で折れることがある。
- 枠線（border）、影、画像部品、グラデーションは未対応。塗り・文字色・角丸のみ。
- 回転、グループ化、複数選択、整列ガイドは未実装。
- 参考画像は `cover` で全面に敷く。元画像の比率が390:844と違うと端が切れる。
- localStorageの容量上限（およそ5MB）を超える参考画像は保存できない。編集中は表示されるが再読込で消える。
- 履歴は60ステップ。ドラッグ1回＝1ステップ（指を離した時点で確定）。
- 要素は最後の1個を削除できない。プロジェクトも最後の1個は削除できない。
- ホーム画面アプリとSafariタブでは、localStorageが別扱いになることがある。作業はどちらかに寄せるほうが安全（渡すときはJSONで移す）。
- iOSは長期間使わないPWAのデータを消すことがある。大事な配置は必ずJSONで書き出しておくこと。
- キャンバスサイズを変えても部品は追従しない。大きく変えるなら作り直しが早い。
- 画像はlocalStorageに入るため、合計5MB程度が上限。大きい写真は事前に縮小しておくこと。
- 大きいキャンバス（1280幅など）をスマホで開くと表示倍率が30%前後まで下がる。細かい調整は横のサイズバーと数値入力で行う。
